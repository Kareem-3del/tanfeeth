# دليل المستخدم لمنصة تنفيذ

الدليل الإرشادي للموظفين: شرح كل صفحة وميزة وإجراء في المنصة، بالعربية الفصحى، بلا محتوى تقني.
المُخرَج: `Tanfeeth-User-Manual-AR.pdf` (١٣ فصلًا، ~٥١٤ صفحة، ~١٠١ صورة شاشة).

## المحتويات

| المسار | ما فيه |
|---|---|
| `chapters/NN-*.html` | نص الفصول (HTML جزئي). **هنا يكون التعديل.** ترتيب الملفات = ترتيب الفصول. |
| `BRIEF.md` | عقد الكتابة: الأسلوب، الممنوعات، العناصر المسموحة، خريطة الفصول. اقرأه قبل أي تعديل. |
| `manual.css` | تنسيق الطباعة (هوية تنفيذ). |
| `build.mjs` | يجمع الفصول ويرقّم الأشكال ويبني الفهرس بأرقام الصفحات الحقيقية ويُخرج PDF بعلامات تنقّل. |
| `shots.mjs` | يلتقط صور الشاشة من البيئة التجريبية لكل `<figure class="shot">` في الفصول. |
| `shots/*.jpg` | الصور الملتقطة. |
| `shots/manifest.json` | أي صورة لأي موضع (`ch-05#3` = الصورة الرابعة في الفصل الخامس). |
| `shots/ids.json` | السجلات التجريبية المستعملة لصفحات التفاصيل (مشروع، خطة، عقد، مورد…). |
| `shots/overrides.json` | ضبط موضع بعينه: رابط آخر، أزرار تُضغط قبل التصوير، مقاس جوال، أو `skip`. |
| `shots/titles.json` | أسماء بديلة لسجلات تجريبية أسماؤها غير لائقة في الصور. |
| `manual.html` | ناتج مؤقت من `build.mjs` (يُعاد توليده). |

## تعديل نص

1. عدّل ملف الفصل في `chapters/` ملتزمًا بعناصر `BRIEF.md` (`h2`/`h3` بمعرّفات تبدأ بـ`ch-NN-`،
   و`.purpose` و`.why` و`.note` و`.tip` و`.warn`، و`span.ui` لنصوص الشاشة، و`span.status` للحالات).
2. ابنِ: `node docs/user-manual/build.mjs` (حوالي ٢٠ ثانية). يحتاج Google Chrome و`pdftotext` (poppler).

## إضافة صورة أو إعادة تصويرها

1. ضع في الفصل: `<figure class="shot" data-route="/portal/plan/:id" data-tab="المراجعة" data-caption="…"></figure>`
   (`data-tab` و`data-action` نصوص تُضغط بالترتيب قبل التصوير).
2. صوّر الفصل: `MANUAL_EMAIL=… MANUAL_PASSWORD=… node docs/user-manual/shots.mjs ch-02`
   أو موضعًا واحدًا: `… shots.mjs "ch-02#6"`. الحساب يجب أن يرى كل الصفحات في demo.tanfeeth.io.
3. إن لزم سجل بحالة معيّنة أو أزرار مختلفة فاضبطها في `shots/overrides.json` بمفتاح الموضع.
   الموضع الذي يفشل فيه ضغط زر لا يُحفظ (حتى لا تصف الصورة غير ما فيها) ويُحذف من الـPDF.
4. أعد البناء.

`shots.mjs` يقرأ الصفحات فقط ولا يرسل أي تعديل. ينظّف أسماء السجلات التجريبية في الردود ويخفي ما يخص وضع العرض
(«وضع العرض»، «أكمِل الخطوة»، «تبديل الحساب (عرض)») لأن موظف الجهة لا يراها.

## مزامنة الدليل مع المنصة

اكتب دائمًا من النسخة **المنشورة** لا من النسخة المحلية:

```bash
git -C frontend-v3 fetch && git -C frontend-v3 worktree add --detach /tmp/manual-fe origin/main
git -C backend fetch && git -C backend worktree add --detach /tmp/manual-be origin/staging
# … راجع الفصل المتأثر مقابل /tmp/manual-fe/src ثم:
git -C frontend-v3 worktree remove /tmp/manual-fe && git -C backend worktree remove /tmp/manual-be
```

## مواضع ناقصة معروفة

صور اللوحة الجانبية لإضافة «اعتماد»، وصفحتا المتعاقد ذواتا الرابط، وحوارات لم يفتحها حساب العرض
(قرار الاعتماد، تسجيل النشر، كتابة الرد والملحق، الإلغاء، إشعارات الترسية، الضمان، مسودة العقد،
…). الفصول تصفها نصًا؛ الصور تُضاف حين تتوفر حالات مناسبة.
