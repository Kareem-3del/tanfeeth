- 10 ملفات من الـ11 متطابقة تمامًا (نفس المعايير والأوزان) بعنوان «نموذج تقييم أداء (خدمات استشارية)» — تُعتمد كـ **النموذج العام** (`نموذج-تقييم-عام.xls`).
- ملف «نظافة المدن» مختلف (3 معايير محتوى محلي + 7 معايير بيئة وصحة وسلامة) — **نموذج نظافة المدن**.

- `procedure-33.txt` = نص الإجراء #33 (الوحدة 15).

درجة المجموعة = متوسط معاييرها، النتيجة = Σ الوزن × درجة المجموعة، مقارنة بفترتين سابقتين، وتوصيات/توقيع لجنة (أعضاء + رئيس).
