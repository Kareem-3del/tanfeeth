# تقرير تطبيق نظام 1448 في منصة تنفيذ

تقرير إنجاز بأسلوب دليل المستخدم وتنسيقه: ما أُنجز لتطبيق نظام المنافسات والمشتريات الحكومية 1448هـ إلى جانب نظام 1440،
بالعربية الفصحى وصور شاشة من demo.tanfeeth.io. المُخرَج: `Tanfeeth-Law-1448-Report-AR.pdf`.
المرجع التفصيلي للبنود (بالملفات ومعايير القبول): `docs/product/LAW-1448-IMPLEMENTATION.md`.

| المسار | ما فيه |
|---|---|
| `chapters/NN-*.html` | نص الفصول (عناصر `BRIEF.md` في دليل المستخدم نفسها). |
| `build.mjs` | نسخة من بنّاء الدليل بغلاف التقرير وتذييله؛ التنسيق من `../user-manual/manual.css`. |
| `shots/` | الصور و`manifest-*.json` و`overrides.json` و`ids.json`. |
| `shots/mock-*.json` | ردود مستبدلة لصور «عرض توضيحي» (مشروع/عقد على نظام 1448 أو لم تتحدد نسخته) — لا توجد هذه الحال في demo لأن 1448 غير مفعّل. |

## إعادة البناء

```bash
cd docs/law-1448-report
MANUAL_DIR=. MANUAL_EMAIL=… MANUAL_PASSWORD=… node ../user-manual/shots.mjs ch-02   # فصل واحد، أو بلا وسيط لكل الناقص
node build.mjs
```

`shots.mjs` هو أداة الدليل نفسها: `MANUAL_DIR` يوجهها إلى هذا المجلد، و`mock` في `overrides.json` يستبدل ردّ قراءة بعينها
(جزء من الرابط → ملف في `shots/`). كل صورة تستعمل `mock` يقول تعليقها «عرض توضيحي».
