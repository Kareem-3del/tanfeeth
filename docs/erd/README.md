## إعادة التوليد بعد أي تعديل على الكيانات

المخطط لقطة زمنية؛ عند إضافة/تعديل كيان أعد التوليد من نفس المصدر
(`backend/docs/erd/tanfeeth.dbml` هي النسخة الأساسية داخل مستودع الـAPI).

## ملاحظات

- العلاقات مستنتجة من أعمدة `*_id` بالتسمية الاصطلاحية (لا توجد قيود FK
  فعلية على مستوى قاعدة البيانات عبر حدود الوحدات — كل وحدة تملك جداولها
  والربط منطقي عبر المنافذ، وفق المعمارية السداسية في `backend/AGENTS.md`).
- `role_permissions` جدول ربط (many-to-many) بين `roles` و`permissions`.
- خدمة `tanfeeth-rfp` لها قاعدة بيانات منفصلة (pgvector) غير مشمولة هنا.
